# Pixel Horde — web playtest (1.17.1)

Play in a browser: **https://mjonathandom-sudo.github.io/pixel-horde-play/**

This is a static copy of Pixel Horde 1.17.1 (vc45) for PC friends who don't have Android. It is the same game as the closed-beta APK, served as a website.

## Controls

- Move: WASD or arrow keys, or click/drag on the left side of the screen
- Dash: J or Space
- Nova: K
- Bag: I, B, F, or Tab
- Pause: P or Escape

## Notes

- Anyone with the link can open this page (the repo and site are public).
- Ads and in-app purchases are not live on the web build. Premium and rewarded-ad prompts use the in-game debug stubs.
- Progress is stored in this browser's local storage (`pixelhorde.save.v1`). Clearing site data, using a different browser, or a different device starts a new save. Web saves do not sync with the Android app.
- This is a playtest build, not a store release.
